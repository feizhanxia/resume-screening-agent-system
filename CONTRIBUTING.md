# Contributing

Thank you for helping improve Resume Screening Agent.

1. Open an issue before large behavioral or architectural changes.
2. Use synthetic resumes only; never commit personal information or API keys.
3. Create a focused branch and add tests for behavior changes.
4. Run `ruff check src tests` and `pytest` before opening a pull request.
5. Keep conclusions evidence-backed and preserve the explicit `uncertain` state.

By submitting a contribution, you agree that it is licensed under the MIT License and that you have
the right to provide it under those terms.
