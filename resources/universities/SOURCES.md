# 中国高校类别目录来源

`university_catalog.json` 仅收录可追溯的官方名单，并随应用离线分发。

- 985工程：教育部《“985工程”学校名单》，2008-04-25。
  <https://www.moe.gov.cn/srcsite/A22/s7065/200612/t20061206_128833.html>
- 211工程：教育部《“211工程”学校名单》，2008-04-25。
  <https://www.moe.gov.cn/srcsite/A22/s7065/200512/t20051223_82762.html>
- 双一流：教育部、财政部、国家发展改革委《第二轮“双一流”建设高校及建设学科名单》，2022-02-14。
  <https://www.moe.gov.cn/srcsite/A22/s7065/202202/t20220211_598710.html>

目录保留来源URL、发布日期和下载文件SHA-256。985、211是历史工程口径；双一流采用第二轮名单。
对于排名前20、综合性大学等没有统一固定官方名单的条件，本目录不作自动判断。
