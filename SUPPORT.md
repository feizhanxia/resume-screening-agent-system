# Support

Use GitHub Issues for reproducible bugs, feature requests, and documentation problems. Before filing:

- Confirm the problem occurs on the latest release.
- Use synthetic resume files and remove personal information from screenshots.
- Include operating system and architecture, release version, document type, and the visible error state.
- Never include API keys, real resumes, local databases, or unredacted logs.

Security issues must follow [SECURITY.md](SECURITY.md), not the public issue tracker.
